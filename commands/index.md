| Command                           | Description                                                  |
| --------------------------------- | ------------------------------------------------------------ |
| [`hush push`](/commands/push)     | Push your local version of the `.env` file to the backend.   |
| [`hush pull`](/commands/pull)     | Pull the newest version of the `.env` file from the backend. |
| [`hush cat`](/commands/cat)       | Outputs the secrets contained in a Hush!-managed secret.     |
| [`hush list`](/commands/list)     | List all Hush! secrets in the backends of your project.      |
| [`hush grant`](/commands/grant)   | Grant access to a secret to another user.                    |
| [`hush revoke`](/commands/revoke) | Revoke access to a secret from another user.                 |
| [`hush delete`](/commands/delete) | Delete the given Hush! secret in its backend.                |
